# learnX 隐私政策

生效日期：2026 年 11 月

learnX 是 Rui Ying（下称“我”）开发的免费开源清华大学网络学堂 App。本政策说明本应用会处理哪些信息、这些信息去往何处，以及您可以做出的选择。本应用的源代码公开在 [github.com/robertying/learnX](https://github.com/robertying/learnX)，您可以核对本政策所述的一切。

## 概要

- 您的清华账号、密码和课程内容保存在您的设备上，只会发送给清华大学自己的服务器（开启下文的课程信息共享时除外）。
- 我没有为 learnX 运营服务器，也不收集您的账号、课程、公告、作业、文件或成绩。
- 崩溃报告和基本使用统计发送给 Google Firebase，其中不包含您的登录信息或课程内容。
- 课程信息共享（courseX）默认关闭。开启后，它上传您本学期课程的公开信息，从不上传关于您本人的信息。

## 您的清华账号

登录时，learnX 需要您的清华账号和密码。通过清华统一身份认证页面登录时，learnX 还会保存该页面用于识别受信任设备的设备标识。

- 它们保存在设备的安全存储中（iOS、iPadOS 和 macOS 上为钥匙串，Android 上为受 Keystore 保护的存储），不会包含在备份中，也不会同步到其他设备。
- 它们只会发送给清华大学的服务器（id.tsinghua.edu.cn 和 learn.tsinghua.edu.cn）用于登录，包括应用在后台刷新时。
- 退出登录会从设备上删除它们，并清除清华网站的登录 Cookie。

## 您的课程内容

learnX 从网络学堂下载您的课程、公告、文件、作业、成绩和课表，并保存在您的设备上以便离线查看。您下载的文件保存在您的设备上。您进行的操作（例如提交作业、收藏）会发送给网络学堂，与在网页上操作相同。

您的设置、归档和隐藏的内容以及作业草稿也只保存在您的设备上。退出登录或删除应用会将其移除。

## 设备功能

以下功能均在您的设备上运行，不会向我发送任何信息：

- **通知**：learnX 在后台查询网络学堂，并在您的设备上发布新内容、成绩、截止时间变更、作业截止提醒和上课提醒的通知。没有推送服务器。
- **日历和提醒事项**：仅在您开启同步后，learnX 才会把课表和作业添加到您选择的日历或提醒事项列表。它会读取您的日历列表供您选择，但不会读取您的其他日程。
- **小组件、聚焦搜索和 Siri**：learnX 向自己的小组件提供即将截止的作业、课程和近期内容；在 Apple 设备上，还会把公告、作业和文件加入系统的本机搜索索引。关闭相应功能或退出登录即可移除。
- **相机、照片和文件**：learnX 只读取您选择或分享给它的照片或文件，用于附加到作业提交中。只有在您要求时，它才会把图片存入照片图库。

learnX 使用通知、日历、提醒事项、相机或照片前，系统会征求您的许可，您可以随时在设备设置中更改。

## 课程信息共享（courseX）

此功能默认关闭。开启后，learnX 会把您本学期课程的信息上传到 courseX（[tsinghua.app](https://tsinghua.app)），任何人都可以查看：课程 ID、课程号和课序号、中英文课程名、教师姓名和工号，以及上课时间和地点。

不会上传任何关于您本人的信息：不包括您的姓名、学号、成绩或账号中的其他内容，上传也不带有任何能识别您或您设备的标识。关闭此功能即停止后续上传。已共享的课程信息描述的是课程而不是您，会保留在 courseX 上。

## 崩溃报告和使用统计

learnX 使用 Google Firebase 发现和修复问题：

- **Firebase Crashlytics**：应用崩溃或出现意外错误时会收到一份报告，内容包括错误及其在代码中的位置、应用版本、设备型号、系统版本、可用内存和存储空间、当时打开的页面、上次后台刷新的情况（用时和获取的条目数），以及一个随机的安装标识。报告中的网址会去掉查询参数，网络学堂返回的内容也不会包含在内，因此报告不含您的课程内容。
- **Firebase Analytics**：统计应用的安装、打开和使用次数，以及应用版本、设备型号、系统版本和根据 IP 地址推断的大致地区。

learnX 不收集广告标识符，不展示广告，也不会在其他应用或网站上跟踪您。使用演示账号时不会发送崩溃报告。Google 按其自身的保留设置和 [Firebase 隐私说明](https://firebase.google.com/support/privacy)保存这些数据。

## 其他连接

- Android 版会查询清华 TUNA 镜像站（mirrors.tuna.tsinghua.edu.cn）是否有新版本，并在您要求时从那里下载更新。
- 更新日志会打开 learnX 在 GitHub 上的发布页面，公告中的链接会打开其指向的网站。这些网站有各自的隐私政策。
- 如果您从 App Store 或 Google Play 安装 learnX，下载由 Apple 或 Google 按其各自的政策处理。

与访问任何网站一样，应用连接这些服务器时，它们可以看到您的 IP 地址。

## 儿童

learnX 面向清华大学学生，不面向 13 岁以下的儿童。

## 本政策的变更

本政策变更时，新版本会连同新的生效日期发布在本页面。您可以在 GitHub 上的项目历史中查看所有旧版本。
