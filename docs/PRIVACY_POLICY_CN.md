# learnX 隐私政策

生效日期：2026 年 11 月

learnX 是 Rui Ying（下称“我”）开发的免费开源清华大学网络学堂应用。本政策说明本应用会处理哪些信息、这些信息去往何处，以及你可以做出的选择。本应用的源代码公开在 [github.com/robertying/learnX](https://github.com/robertying/learnX)，你可以核对本政策所述的一切。

## 概要

- 你的清华账号、密码和课程内容保存在你的设备上，只会发送给清华大学自己的服务器（开启下文的课程信息共享时除外）。
- 我不收集你的账号、课程、公告、作业、文件或成绩。应用向我的更新服务器查询更新时，也不会发送这些信息（见下文“其他连接”）。
- 崩溃报告和基本使用统计发送给 Google Firebase（Windows 和 Linux 版不发送），其中不包含你的登录信息或课程内容。
- 课程信息共享（courseX）默认关闭。开启后，它上传你本学期课程的公开信息，从不上传关于你本人的信息。

## 你的清华账号

登录时，learnX 需要你的清华账号和密码。通过清华大学用户电子身份服务系统的登录页面登录时，learnX 还会保存该页面用于识别受信任设备的设备标识。

- 它们保存在设备的安全存储中（iOS、iPadOS 和 macOS 上为钥匙串，Android 上为受 Keystore 保护的存储），不会包含在备份中，也不会同步到其他设备。
- Windows 和 Linux 版使用系统为你的账户提供的保护对其加密（Windows 数据保护；Linux 上为通过 Secret Service 或 KWallet 使用的密钥环），并保存在电脑上的应用数据文件夹中：Windows 上位于本地用户配置文件，不会随漫游配置文件同步到其他电脑。Linux 上没有密钥环时不会保存，你每次都需要登录。备份主文件夹时可能包含其加密副本。
- 它们只会发送给清华大学的服务器（id.tsinghua.edu.cn 和 learn.tsinghua.edu.cn）用于登录，包括应用在后台刷新时。
- 退出登录会从设备上删除它们，并清除清华网站的登录 Cookie。

## 你的课程内容

learnX 从网络学堂下载你的课程、公告、文件、作业、成绩和课表，并保存在你的设备上以便离线查看。你下载的文件保存在你的设备上。你进行的操作（例如提交作业、收藏）会发送给网络学堂，与在网页上操作相同。

你的设置、已归档和已屏蔽的内容以及作业草稿也只保存在你的设备上。退出登录或删除应用会将其移除。

在 Windows 上，卸载 learnX 会移除它保存的一切：已保存的登录信息、设置、缓存的内容、已下载的文件，以及“登录时启动”项。在 Linux 上，删除 AppImage 或卸载软件包后，learnX 的数据文件夹（`~/.config/learnX`）仍会保留，其中有加密的登录信息和已下载的文件：请先退出登录，或自行删除该文件夹。

## 设备功能

以下功能均在你的设备上运行，不会向我发送任何信息：

- **通知**：learnX 在后台查询网络学堂，并在你的设备上发布新内容、成绩、截止时间变更、作业截止提醒和上课提醒的通知。没有推送服务器。
- **日历和提醒事项**：仅在你开启同步后，learnX 才会把课表和作业添加到你选择的日历或提醒事项列表。它会读取你的日历列表供你选择，但不会读取你的其他日程。
- **小组件、聚焦搜索和 Siri**：learnX 向自己的小组件提供即将截止的作业、课程和近期内容；在 Apple 设备上，还会把公告、作业和文件加入系统的本机搜索索引。关闭相应功能或退出登录即可移除。
- **相机、照片和文件**：learnX 只读取你选择或分享给它的照片或文件，用于附加到作业提交中。只有在你要求时，它才会把图片存入照片图库。

learnX 使用通知、日历、提醒事项、相机或照片前，系统会征求你的许可，你可以随时在设备设置中更改。Windows 和 Linux 在应用显示通知前不会征求许可：你可以在 learnX 的设置或系统的通知设置中关闭通知。Windows 和 Linux 版没有小组件、搜索索引、日历同步、相机或照片图库功能；它会把课表和作业截止时间导出为日历文件，保存到你选择的位置。

## 课程信息共享（courseX）

此功能默认关闭。开启后，learnX 会把你本学期课程的信息上传到 courseX（[tsinghua.app](https://tsinghua.app)），任何人都可以查看：课程 ID、课程号和课序号、中英文课程名、教师姓名和工号，以及上课时间和地点。

不会上传任何关于你本人的信息：不包括你的姓名、学号、成绩或账号中的其他内容，上传也不带有任何能识别你或你设备的标识。关闭此功能即停止后续上传。已共享的课程信息描述的是课程而不是你，会保留在 courseX 上。

## 崩溃报告和使用统计

iOS、iPadOS、macOS 和 Android 版使用 Google Firebase 发现和修复问题；Windows 和 Linux 版不发送崩溃报告或使用统计：

- **Firebase Crashlytics**：应用崩溃或出现意外错误时会收到一份报告，内容包括错误及其在代码中的位置、应用版本、设备型号、系统版本、可用内存和存储空间、当时打开的页面、上次后台刷新的情况（用时和获取的条目数），以及一个随机的安装标识。报告中的网址会去掉查询参数，网络学堂返回的内容也不会包含在内，因此报告不含你的课程内容。
- **Firebase Analytics**：统计应用的安装、打开和使用次数，以及应用版本、设备型号、系统版本和根据 IP 地址推断的大致地区。

learnX 不收集广告标识符，不展示广告，也不会在其他应用或网站上跟踪你。使用演示账号时不会发送崩溃报告。Google 按其自身的保留设置和 [Firebase 隐私说明](https://firebase.google.com/support/privacy)保存这些数据。

## 其他连接

- iOS、iPadOS、macOS 和 Android 版会在启动时，以及你离开一小时以上再回到应用时，向我的更新服务器（ota.tsinghua.app）查询应用代码的更新，有更新时会下载。查询中包含应用版本、平台、当前运行的更新和一个随机的安装标识符；如果应用上次运行时因错误退出，还包含该错误信息。查询中不含你的账号或课程的任何信息。
- Android 版会查询清华 TUNA 镜像站（mirrors.tuna.tsinghua.edu.cn）是否有新版本，并在你要求时从那里下载更新。Windows 和 Linux 版在运行时查询同一镜像是否有新版本，并在后台下载：Windows 版和 AppImage 会自动安装更新，.deb 版则由你在设置中通过系统的安装程序安装。
- 更新日志会打开 learnX 在 GitHub 上的发布页面，公告中的链接会打开其指向的网站。这些网站有各自的隐私政策。
- 如果你从 App Store 或 Google Play 安装 learnX，下载由 Apple 或 Google 按其各自的政策处理。

与访问任何网站一样，应用连接这些服务器时，它们可以看到你的 IP 地址。

## 儿童

learnX 面向清华大学学生，不面向 13 岁以下的儿童。
